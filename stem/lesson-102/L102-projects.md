**Time allocation**: 10 min.

Students work in teams to improve the “Weight” experiment in the Playground app:

1. They replace the text node on the dashboard with a gauge node and set it up as a traffic light for three weight ranges
2. They add more students to the flow
3. They create a “weight calibration” function (a function node) that subtracts 5 kg from the measured value
